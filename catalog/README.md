# 風格配方資料
`python3 catalog/generate.py` 重新產生 `data/art.json` 和 `data/photo.json`（僅 Python 標準庫；無需網路）。`python3 catalog/check.py` 驗證已提交版本、計數與結構。JSON 每庫可單獨擷取。

- **美術：**七類、42 個技法家族。每家族 24 個場景配方，共 1,008 張卡。先用固定場景對照跨技法差異；提示逐家族指明媒材、筆觸、表面、明暗、構圖與色盤。單色技法覆寫場景配色，不把素描錯誤描述成彩色塗漬。
- **攝影：**七類、42 個攝影／光學／顯影家族，每家族採與拍法相容的 8 組場景，再各做 3 個有用途的取景方向，共 1,008 張卡。不是把所有技法隨機套在所有場景；微距、俯視、動態和拼接分別有專門取景。光線技法覆寫不適用的場景光設定。
- 每張卡是**可操作的視覺配方**，不是互不相干的 2,016 個歷史流派、實拍照片或模型實測結果。所有場景寫作、提示與資料編排為本專案原創；不複製社群貼文、絕不轉載社群圖片。社群觀察與教育來源另列，並非逐卡出處。
- JSON 中 `id` 及 `familyId` 用於深連結及收藏，請勿重新排序家族內已有條目；名稱中英雙語，`prompt` 為繁中、`promptEn` 為英文。每卡 `preview` 是程式製作示意圖的描述，不保證生成模型輸出相同畫面。
