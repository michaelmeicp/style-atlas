# Style Atlas｜美術與攝影風格圖庫

可依繁中／英文關鍵字與分類找圖、收藏、並排比較，或複製提示詞。兩庫各有 **42 個技法家族、1,008 個視覺配方**。配方是媒材、光線、取景、場景等可以重複運用的做法，不代表各有一千個歷史流派。

- 美術卡：原創的程序化圖像示意。
- 攝影卡：為呈現光學及光線變化製作的原創合成影像，不是實拍照片，也不是提示詞在任一模型的實測輸出。
- 社群只用可核對的公開資訊做靈感參考。沒有複製、直連或收錄社群圖片和整段提示詞。可讀範圍與技術來源見[來源說明](research/INSPIRATION.md)。
- 無帳號、追蹤、遠端圖像 API 或外部字型。收藏留在當前瀏覽器。同一場景比較是為了看清技法差異，不代表生成模型的結果。

## 本機啟動

```sh
python3 -m http.server 8080 --bind 127.0.0.1
# 開啟 http://127.0.0.1:8080/
```

不需在本機產生影像。此為靜態網站，連結及素材皆用相對路徑，可從 GitHub Pages 的儲存庫子路徑載入。首次瀏覽資料按圖庫分開載入，卡片分頁、圖片延遲載入。

## 驗證

```sh
python3 catalog/check.py
node --test gallery.test.mjs tests/check-previews.mjs
```

[資料再生規則](catalog/README.md)和原始家族字典位於 `catalog/`；美術圖由 `preview.mjs` 繪製，攝影模擬器在 `preview-tools/`。本庫不含影片、影像生成服務或模型會得出同一畫面的保證。
